# Supabase Migration Setup Guide

## Step 1: Create Supabase Project

1. Go to https://supabase.com and create a new project
2. Choose a strong database password (save it!)
3. Select the closest region (Mumbai for India)
4. Wait for the project to be created (~2 minutes)

## Step 2: Get Your Keys

From **Project Settings > API**:
- `Project URL` → This is your `VITE_SUPABASE_URL`
- `anon public` key → This is your `VITE_SUPABASE_ANON_KEY`
- `service_role` key → Used by Edge Functions (auto-available)

## Step 3: Run the Database Migration

1. Go to **SQL Editor** in your Supabase dashboard
2. Open the file `supabase/migrations/001_initial_schema.sql`
3. Copy the ENTIRE content and paste it in the SQL Editor
4. Click **Run** — this creates all 13 tables, triggers, functions, and RLS policies

**Important**: If `pg_cron` is not enabled, go to **Database > Extensions** and enable `pg_cron` first.

## Step 4: Enable Google Auth (Optional)

1. Go to **Authentication > Providers > Google**
2. Enable Google provider
3. Add your Google Client ID and Secret
4. Set redirect URL to: `https://your-project.supabase.co/auth/v1/callback`
5. In Google Cloud Console, add this redirect URL to your OAuth client

## Step 5: Deploy Edge Functions

Install Supabase CLI:
```bash
npm install -g supabase
```

Login and link:
```bash
supabase login
supabase link --project-ref your-project-ref
```

Set secrets:
```bash
supabase secrets set RAZORPAY_KEY_ID=rzp_test_xxx
supabase secrets set RAZORPAY_KEY_SECRET=xxx
supabase secrets set CLOUDINARY_CLOUD_NAME=xxx
supabase secrets set CLOUDINARY_API_KEY=xxx
supabase secrets set CLOUDINARY_API_SECRET=xxx
supabase secrets set SMTP_USER=your-email@gmail.com
supabase secrets set SMTP_PASS=your-app-password
```

Deploy all functions:
```bash
supabase functions deploy razorpay
supabase functions deploy purchase-website
supabase functions deploy admin
supabase functions deploy send-email
supabase functions deploy upload-image
supabase functions deploy bookings
supabase functions deploy careers
```

## Step 6: Update Frontend Environment

Create `Frontend/.env` (copy from `Frontend/.env.example`):
```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
VITE_RAZORPAY_KEY_ID=rzp_test_xxx
```

## Step 7: Install Frontend Dependencies

```bash
cd Frontend
npm install @supabase/supabase-js
npm uninstall axios @react-oauth/google googleapis
```

## Step 8: Create Admin User

In Supabase SQL Editor:
```sql
-- After registering via the app, make yourself admin:
UPDATE profiles SET role = 'admin' WHERE email = 'your-email@example.com';
```

## Step 9: Migrate Existing Data

If you have existing templates in MongoDB, you'll need to:
1. Export from MongoDB (mongoexport or a script)
2. Transform the data to match the new PostgreSQL schema
3. Import into Supabase (via SQL INSERT or CSV import)

Key field name changes:
- `_id` → `id` (UUID, auto-generated)
- `previewImage` → `preview_image`
- `liveDemo` → `live_demo`
- `withBackend` → `with_backend`
- `creditsRequired` → `credits_required`
- `isActive` → `is_active`
- `whatsIncluded` → `whats_included`
- `templateInfo` → `template_info`
- `developmentProcess` → `development_process`
- `displayId` → `display_id` (auto-generated by trigger)

## Step 10: Deploy Frontend

Push the updated frontend to your repo. Vercel will auto-deploy.

Make sure these env vars are set in Vercel:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`
- `VITE_RAZORPAY_KEY_ID`

## Step 11: Remove Render

Once everything is working on Supabase:
1. Test all features (login, register, Google login, buy credits, purchase website, chat, admin panel)
2. Delete the Render service
3. Remove the `Backend/` folder from the repo (optional, keep as reference)

## Architecture Summary

```
Before: Frontend (Vercel) → Express API (Render) → MongoDB Atlas
After:  Frontend (Vercel) → Supabase (PostgreSQL + Edge Functions + Auth)
```

- **Auth**: Supabase Auth (email/password + Google OAuth)
- **Database**: Supabase PostgreSQL with RLS
- **Server Logic**: Supabase Edge Functions (Deno)
- **Images**: Cloudinary (unchanged)
- **Payments**: Razorpay (unchanged, called via Edge Functions)
- **Emails**: Gmail SMTP via Edge Functions (denomailer)
- **Cron Jobs**: pg_cron (progress updater every 54 minutes)
